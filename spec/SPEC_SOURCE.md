## Rule

**Do not edit the copy.** If the spec must change, it is changed in `art-stream-rec` (by the user, through the recorder workflow) and copied here again; then this file is updated with the new commit and hashes.

If the spec and the plugin code disagree, the spec wins. If the spec looks wrong or ambiguous, stop and ask the user; do not "fix" the copy.
